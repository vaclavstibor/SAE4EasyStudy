Steering Setup
How SAE feature steering is combined with the base recommender. See docs/equations.md §10. Feature-conditioned adds an adaptive γ·SAE score on top of CF (current production default). Latent perturbation decodes the SAE adjustment vector back to embedding space and adds α·direction to the user seed; ranking is pure CF on the rotated seed. Constrained subset keeps only items whose SAE score ≥ τ × max-positive-SAE, then ranks the survivors by base CF (falls back to base ranking if no item satisfies the constraint).
